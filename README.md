> **#OmSarvaDevaGanayaNamaha 🕉️🙏🚩** > An automated, NFC-triggered, high-tech personal health monitoring system built using **Google Apps Script**, **Google Sheets**, and responsive **HTML5/CSS3** dark-mode UI.

---

## 📌 Project Overview

This project provides an automated fitness ecosystem that tracks daily physical activity, nutrition breakdown, hydration, and sleep patterns without relying on complex third-party mobile applications. 

By leveraging **Physical NFC Tags**, the system presents a tailored, mobile-responsive dark-theme Web App to instantly submit exercise logs and daily intake metrics. The backend automatically calculates nutritional breakdowns, maintains time-series metrics, updates a **Dynatrace-Style Dark Dashboard**, and emails periodic PDF fitness reports.

---

## 🛠️ Key Features

* **📱 NFC Tag Integration:**
  * **Tag 1 (Workout Area):** Instant launch of exercise forms (Kapalabhathi, Jog, Push Ups, Planks, Squats, Walk, etc.).
  * **Tag 2 (Kitchen / Bedside):** Instant launch of Diet (Pure Veg), Hydration, and Sleep tracking interfaces.
* **🥗 Intelligent Macro Segregation:** Automatically categorizes food intake into Carbohydrates, Simple Carbohydrates, Sugars, Fats, Proteins, Nutrients, Micro-nutrients, and Fiber.
* **📊 Dynatrace-Style Dark Dashboard:** A real-time data monitoring dashboard formatted inside Google Sheets with dark mode styling, metrics charts, and color-coded statuses.
* **⏰ Automated Background Engine:**
  * **15 Mins:** Aggregates Daily, Weekly, and Monthly fitness totals.
  * **20 Mins:** Refreshes and formats the Dynatrace visual dashboard view.
  * **4 Hours:** Evaluates trends and posts AI-driven feedback and actionable suggestions.
  * **5 Hours:** Converts dashboard views into PDF reports and emails them directly to `mruthyunjayamath@gmail.com`.
